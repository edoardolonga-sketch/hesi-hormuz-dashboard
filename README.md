# HESI / HSI Decision Dashboard

Hormuz Analytics dashboard for observed stress, scenario analysis, predictive governance and multi-horizon ML experiments.

## Architecture

- HESI: observed/data-derived stress
- HSI: hypothetical scenario analysis
- Predictive Core: market return, momentum and volatility features
- Economic / Scenario: physical, buffer, route and exposure variables
- Excluded / Robustness: variables retained for benchmarking or robustness analysis

## Deployment

Next.js dashboard deployed on Vercel and connected to this GitHub repository.

## Methodological principle

Economic relevance does not imply incremental predictive relevance. Model updates follow anti-leakage and out-of-sample validation rules.
